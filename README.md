## 🎯 About the Game

**Elite Battleground** is a fast-paced 3D action/fighting game inspired by modern battle royale titles. Drop into the arena, grab weapons, and fight to be the last one standing.

### ✨ Features

- 🎮 Fast-paced 3D combat
- 🔫 Multiple weapons with unique stats
- 🏃 Advanced movement (sprint, crouch, jump)
- 🤖 AI enemies with combat behavior
- 🌐 Multiplayer support (coming soon)
- 📱 Cloud-based development (no local PC required!)

## 🚀 Quick Start (No PC Required!)

### Prerequisites
- GitHub account
- Web browser (Chrome/Firefox recommended)
- Internet connection

### Steps

1. **Open in Codespaces**
   - Click the `Code` button on this repo
   - Go to `Codespaces` tab
   - Click `Create codespace on main`

2. **Wait for Setup**
   - The devcontainer will automatically install Godot 4 and VNC
   - This takes 2-3 minutes

3. **Launch Godot**
   - Open the `Ports` tab in VS Code
   - Click the globe icon next to port `8080`
   - This opens noVNC in your browser

4. **Start Developing**
   - In the VNC desktop, open Godot 4
   - Import the `game/` folder
   - Start building!
